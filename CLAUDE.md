## Running the Project

Use the helper script for Docker-based execution:

```bash
bash scripts/run.sh
# Choose 1 for Scrape (crawler only)
# Choose 2 for Production (all services, background)
```

Or invoke Docker Compose directly:

```bash
# Run the crawler phase only
docker compose --profile scrape up --build

# Run the full production stack
docker compose --profile production up --build -d
```

**Service URLs (production profile):**
- Neo4j browser: http://localhost:7474 (bolt: `bolt://localhost:7687`, credentials: `neo4j/password`)
- RAG API: http://localhost:8000
- React Interface: http://localhost:3000

## Architecture

This is a scaffold-stage project — all four services have Dockerfiles and READMEs but **no implementation code yet**. The architecture is:

```
crawler/ → graph (Neo4j) → rag/ → interface/
```

### Phase 1: `crawler/` — Semantic Crawler
- **Runtime:** Node 20 / Playwright
- Headless browser navigates the target site (IMDB), parses interactive DOM elements (buttons, forms, links, ARIA roles) — does **not** scrape text content
- Must simulate human-like behaviour (throttled speed, cookie banner handling, transparent User-Agent) to avoid anti-bot detection
- Output: nodes/edges in the graph schema (see below)

### Phase 2: `graph/` — UI Knowledge Graph
- **Storage:** Neo4j
- **Nodes** = UI states (what the user sees). Each node has a `capabilities` object and `available_elements` array with CSS selectors
- **Edges** = interactions between states (`interaction_type`: click/input, `target_element_id`, source/target node IDs)
- Schema is defined in `docs/CONTEXT.MD`

### Phase 3: `rag/` — RAG + LLM Brain
- **Runtime:** Python 3.11 / LangChain
- Embeds user manuals/documentation into a vector DB
- On user query: retrieves relevant manual chunks → translates intent → queries Neo4j graph to find the exact click-path
- Exposes an API on port 8000 consumed by the interface
- Connects to Neo4j via env vars: `NEO4J_URI`, `NEO4J_USER`, `NEO4J_PASSWORD`

### Phase 4: `interface/` — Chat UI
- **Runtime:** Node 20 / React
- Conversational chat UI where users ask how to do things on the target website
- Renders mixed responses: text explanations + on-the-fly recorded video tutorials (`.webm`/`.mp4`) generated by a backend Playwright script executing the retrieved click-path

## Key Data Schema

Graph nodes and edges follow this structure (full example in `docs/CONTEXT.MD`):

```json
{
  "nodes": [{ "node_id": "", "type": "page", "description": "", "capabilities": {}, "available_elements": [{ "element_id": "", "role": "", "css_selector": "" }] }],
  "edges": [{ "edge_id": "", "source_node": "", "target_node": "", "interaction_type": "click", "target_element_id": "" }]
}
```
